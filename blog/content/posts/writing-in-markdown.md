这篇文章既是示例，也是速查表。写新文章时可以直接对着改。

## 新建一篇

```bash
cd blog
../.tools/hugo new content posts/my-new-post.md
```

生成的文件默认是 `draft: true`，写完之后把 `draft` 改成 `false`，或者发布时加 `-D`。

## 常用语法

### 标题

用 `##` 到 `####`。一级标题 `#` 留给文章标题，正文里不要再用，否则目录会乱。

### 强调与链接

**粗体**、*斜体*、`行内代码`，以及 [链接](https://gohugo.io/)。

### 列表

- 无序列表
- 支持嵌套
  - 像这样
1. 有序列表
2. 第二项

### 引用

> 引用适合放别人的话，或者一段需要被强调的结论。
>
> 可以有多段。

### 代码块

带语言标注就会语法高亮，鼠标移上去右上角有复制按钮：

```go
package main

import "fmt"

func main() {
	fmt.Println("hello, world")
}
```

## 排版上的几个小建议

1. 一段只讲一件事，超过五句就分段。
2. 中英文之间加空格，读起来会舒服很多。
3. 代码块前面说清楚“这是在哪个目录、为了解决什么问题”。
4. 图片尽量压缩，宽度 1200px 以内足够。

## 封面与摘要

在 front matter 里写 `summary` 会覆盖自动截取的摘要；`<!--more-->` 之前的内容也会被当作摘要使用。
