前面几篇文章都是在本地的编辑器里写好、再敲命令发上去的。对偶尔写一次的人没什么，但想随手记点东西的时候，光是"打开终端、切目录、起服务"就足够让人放弃了。

所以今天补上了最后一块：**在浏览器里直接写**。

## 现在的流程

1. 打开后台，用 GitHub 登录；
2. 新建一篇，填标题、写正文、拖一张图进去；
3. 点保存。

剩下的交给 GitHub Actions：它会装 Hugo、构建，再把生成的静态文件同步到服务器的 `/var/www/blog`，整个过程通常一分钟以内。

## 为什么还是静态站

后台是后台，站点还是那个纯静态的站点。没有数据库、没有登录入口暴露在公网、没有需要打补丁的 PHP。写作的便利放在管理端，访问的安全性留在前端，这两件事本来就不该互相拖累。
