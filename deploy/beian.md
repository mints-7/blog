# mints.vip 备案注意事项（阿里云 ICP 备案）

站点：Hugo 静态博客，部署在阿里云 ECS `8.163.135.192`（华南1 广州，实例 `i-7xvbtv418jwrrgpb95sg`）。
现状：域名未备案，阿里云对 `Host/SNI = mints.vip` 的 80/443 请求直接拦截（HTTP 403，HTTPS 连接重置）。
裸 IP `http://8.163.135.192` 不受影响，可正常访问。

## 一、备案前必须有

| 条件 | 说明 |
| --- | --- |
| 域名实名认证 | 在阿里云域名控制台完成，`.vip` 需实名通过（通常 1–2 天） |
| 服务器包年包月 | ECS 必须**包年包月**且剩余时长 ≥ 3 个月；按量付费实例不能备案 |
| 备案服务号 | 在 ECS 实例详情页「备案」处申请，一台包年包月实例可申请 5 个 |
| 主体资料 | 个人：身份证正反面、本人手机号、应急联系电话、邮箱 |
| 核验 | 阿里云 App 人脸核验（现在多数省份不再需要幕布拍照） |

## 二、流程（广东管局）

1. 阿里云 App → 备案 → 开始备案，选「首次备案」
2. 填写主体信息（个人）、网站信息：
   - 网站名称：如「拾光笔记」或「mints 的博客」，**不能**出现「中国」「国家」「新闻」「政府」等词
   - 网站内容：博客 / 个人学习记录，服务内容选「其他」或「博客」
   - 域名：`mints.vip`（www 不需要单独备案，随主域名）
3. 上传身份证、人脸核验 → 提交
4. 阿里云初审（1–2 个工作日，会打电话核实）
5. 管局审核（广东通信管理局，法定 20 个工作日，实际通常 3–7 天）
6. 收到备案号短信后，在网站底部放备案号并链接 `https://beian.miit.gov.cn/`

## 三、备案期间站点状态

- 初审通过前，站内部分省份要求「网站不可访问」或显示「备案中」提示页
- 如需切换提示页，执行：
  ```bash
  ssh -i deploy/.ssh/blog_deploy root@8.163.135.192 \
    'echo "<h1>网站备案中</h1>" > /var/www/blog/index.html'
  ```
  备案通过后重新 `./deploy/deploy.sh` 恢复
- 底部备案号：在 `blog/hugo.toml` 加 `params.icp = "粤ICP备xxxxxxxx号"`，页脚已预留位置（待加）

## 四、备案通过后的收尾

1. 确认 `http://mints.vip` 不再被拦（`curl -I http://mints.vip` 应为 301）
2. 证书续期恢复可用（HTTP-01 又能通了），`certbot renew --dry-run` 验证
3. 重新 `./deploy/deploy.sh`
4. 若之前用了 Cloudflare Tunnel/代理，把 DNS 改回阿里云 A 记录 `8.163.135.192`

## 五、风险点

- 证书 2027-02-18 到期，正常会在 1 月中自动续期；若那时仍未备案，需要改用 DNS-01（阿里云 DNS API）签发
- `www.mints.vip` 已加 CNAME → `mints.vip`，备案通过后同一条证书即可覆盖（`--expand` 加 www 即可）
